# Liberto — سازنده‌ی هوشمند اپ‌های اندروید

Liberto یک اپلیکیشن اندروید است که با یک هوش مصنوعی، **برنامه می‌سازد**:

1. **چت** با هر مدل OpenRouter (انتخاب آزاد از ۴۶۰+ مدل، بدون محدودیت)
2. **صوت و ویدیو** در چت (ضبط صدا با میکروفون + ارسال و نمایش ویدیو)
3. **برنامه‌ساز**: توصیف اپ → AI کل کد را می‌نویسد → کد به GitHub شما push می‌شود →
   GitHub Actions آن را در ابری کامپایل می‌کند → فایل نصب (APK) آماده به دست شما می‌رسد.

## تکنولوژی‌هایی که برنامه‌ساز پشتیبانی می‌کند
- ⭐ **Android Native (Kotlin)** — اولویت اول
- Android Native (Java)
- **C++ / NDK** (هسته‌ی C++ با JNI + رابط کاتلین)
- Flutter

## استک خودِ Liberto
- Flutter (UI)
- Kotlin (ذخیره‌ی امن کلیدها با Android Keystore + MediaPlayer)
- C++ / NDK (SHA-256 و شناسه‌ی پیام‌ها از طریق JNI)
- Java (بایت‌کد کامپایل‌شده)

## کلیدها
- **OpenRouter**: در تنظیمات → کلید API (برای چت و برنامه‌ساز)
- **GitHub**: در تنظیمات → یوزرنیم + توکن (برای push کد و بیلد ابری)

هر دو کلید به‌صورت **رمزنگاری‌شده** در Android Keystore ذخیره می‌شوند.

## ساخت APK (مستقیم)
```bash
flutter pub get
flutter build apk --release
```

## بیلد ابری
هر push به این ریپو، GitHub Actions را فعال می‌کند و APK را به‌عنوان artifact
(بند `liberto-apk`) آماده می‌کند.
